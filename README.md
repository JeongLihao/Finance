# Finance — Minecraft 服务器金融系统模组

给服务器加了一套虚拟经济系统

**版本：** 0.4.0  
**平台：** Minecraft 1.20.1 / Forge 47.4.16  
**作者：** H-Jeong

---

## 功能概览

### 账户系统

每个玩家自带银行账户，支持存款、取款、转账。挂单时资金自动冻结，成交扣款，取消退回，杜绝超支。

新玩家首次加入自动获得 **1000 初始资金**。

### 商品系统

默认注册 3 种商品（铁锭、小麦、石头），均可对应 Minecraft 物品。管理员可通过 GUI 或命令动态添加任意 MC 物品（原版/模组均可）作为可交易商品。

每个玩家有独立的商品库存，与 Minecraft 物品栏分离。可通过**存取系统**在两者之间搬运物品。

**存取机制：**
- **存入** — 将 MC 物品栏中的物品存入虚拟商品库存（用于交易）
- **取出** — 将虚拟商品库存中的物品取回 MC 物品栏（满了掉地上）

### 市场交易

**P2P（玩家对玩家）**

挂限价单，买方出价 ≥ 卖方要价自动撮合，支持部分成交。成交价按卖方定价，买方差额自动退回。

**国际市场**

随时买卖，双向报价（买入价/卖出价有 5% 价差）。库存变化驱动价格，每日自动补货和外部消耗，防止价格单向漂移。

### 定价引擎

```
最终价格 = 基本面价格 × (1 + 交易动量) + 噪音偏移
```

| 因子 | 占比 | 说明 |
|------|------|------|
| 基本面 | ~70% | 国际市场库存偏离参考值 1% → 价格变动 5% |
| 交易动量 | ~20% | 每笔交易产生短期冲击，每分钟衰减 50% |
| 市场噪音 | ~10% | 随机游走，模拟运输成本和信息误差 |

价格波动范围：基准价的 10% ~ 1000%。每日自动重置日内统计（开盘价、最高、最低、成交量）。

### 公司系统

花 10,000 创建公司，可选行业（对应 MC 物品栏分类）：

| 行业 | 每日产出 |
|------|----------|
| 原材料 | 铁锭×100 |
| 建筑方块 | 石头×120 |
| 食物 | 小麦×80 |

每 MC 天公司自动生产并卖出 50% 产出变现。原料不足时尝试从国际市场购买，不会因缺料而完全停产。公司估值 = 现金 + 库存市值。

服务器自带 3 个系统公司：铁锭原料（原材料）、石材工坊（建筑方块）、麦田农庄（食物）。

支持通过 GUI 或命令创建：`/company create 原材料 我的公司` 或 `/company create RAW_MATERIALS 我的公司`。

**强制退市机制：** 当管理员删除某个商品时，如果某公司的行业依赖该商品（即公司的 dailyProduction 包含该商品），该公司将被强制退市。退市时公司剩余资金的 10% 均分给当时在线的所有玩家，对应的股票也会被移除。全服广播通知。

### 股票系统

系统公司自动生成股票，玩家可在 GUI 股票页按当前价买卖。系统保存股票列表、流通股、成交量和玩家持仓。

### 事件系统

三个独立计时器，可同一天同时触发：

| 等级 | 影响幅度 | 持续时间 | 触发间隔 |
|------|----------|----------|----------|
| 小事件 | ±5%~10% | 0.5~1 MC天 | ~3 小时 |
| 重大事件 | ±15%~25% | 1~3 MC天 | ~15 小时 |
| 黑天鹅 | ±40%~60% | 2~5 MC天 | ~75 小时 |

### 管理员物品管理

管理员（OP 2）可通过 GUI 管理标签页添加/删除商品，管理页分为三个子标签：

- **从手中添加** — 手持物品，点击按钮自动识别物品 ID、显示名、推荐分类；下方提供手动添加表单
- **常用物品** — 常用 MC 物品按分类列表展示，每项显示物品图标、名称和基础价格，点击即可添加（已注册的自动灰显）
- **已注册商品** — 查看和删除已注册商品

支持任意 MC 物品（原版和模组），自动推断分类（建筑方块、原材料、工具、战斗、食物、红石、药水、交通运输、杂项）。

### GUI 界面

金融中心 GUI，用 `/market gui`、`/finance gui` 或快捷键 `F` 打开。面板式设计，不遮挡游戏画面。商品名全部显示中文。

管理员可见 7 个标签页，普通玩家 6 个：

- **行情** — 国际市场行情表（带物品图标），点击表格行选中商品，下方直接输入数量买入卖出
- **交易** — P2P 挂单，商品通过**分类下拉菜单**选择（按分类组织，带物品图标，支持展开/折叠和滚动）
- **订单** — 查看和取消挂单
- **库存** — 余额、商品库存（虚拟库存 + MC 物品栏数量），支持存入/取出操作，点击行选中商品
- **公司** — 查看/创建公司
- **股票** — 股票买卖和持仓
- **管理** — 商品管理（仅管理员，含三个子标签）

## 游戏内循环

| 间隔 | 发生什么 |
|------|----------|
| 每 MC 天（24000 tick） | 重置日内统计 → 触发事件 → 公司生产+交易 → 国际市场补货/消耗 |
| 每 3 分钟（3600 tick） | 市场噪音刷新 + 动量衰减 + 价格重算 |
| 每 1 分钟（1200 tick） | 交易动量衰减 + 价格重算（与 3 分钟不重叠） |

## 数据存储

所有数据存在世界存档（NBT），服务器重启不丢失。

- `finance_data` — 账户、交易记录、订单、行情、事件、公司、股票、持仓、商品定义
- `finance_inventory` — 玩家商品库存

3. 启动服务器即可
