# 探索、调查与世界生成策略

## 技术选择

Finance 0.4.1 的第 10 阶段采用安全 MVP。Forge 1.20.1 的 jigsaw、动态结构注册、structure set 与二进制模板必须同时正确，且服务器配置不能通过 `/reload` 让已生成区块消失。当前工程此前没有世界生成注册层，因此首版不把实验遗迹注入生物群系，也不修改原版 biome source、seed、矿物或村庄。

仓库遗迹和路边贸易站以稳定 JSON 蓝图交付，尺寸分别为 7×5×7 与 5×4×7；它们可供后续正式结构模板制作和数据包启用。蓝图不属于 Minecraft 的活动 worldgen registry，因此不会意外生成或修改旧世界。`worldgenEnabled=false` 是明确的安全默认值，切换世界生成未来必须完整重启，`/reload` 不会重生成已有区块。

## 当前可玩闭环

1. 制作资源调查板：木板、指南针和线。
2. 在距离已登记聚落或仓库至少 48 格的位置使用。
3. 服务端在同维度、默认 4096 格以内的已登记目标中选择最近一个，不查询未加载区块。
4. NPC 市场必须有足够余额；奖励申请时转入独立 escrow。
5. 玩家得到只含任务 UUID 的调查凭证。使用凭证只显示方向、估计距离和地方主题。
6. 在目标聚落贸易站或仓储控制器实际交互后结算；客户端声明坐标无效。
7. 过期或玩家潜行取消时，完整预算退回 NPC。支付失败不会推进任务状态。

每名玩家最多一个活动调查，默认冷却 2 MC 日、有效期 7 日。目标、冷却、状态和 escrow 引用随世界存档保存；玩家死亡、下线、跨维度和区块卸载不会重复付款。

## 地方主题

地方主题只来自当前位置已加载生物群系的注册名：平原贸易、山地材料、沙漠补给、湿地、海运和下界运输。它们只影响文字和未来任务候选，不保证资源刷新、不定位矿脉，也不直接改变价格。

## 战利品审计

两张遗迹战利品表只包含纸、书、线、指南针、少量铜/铁粒/红石和无绑定调查凭证。不存在余额、账户、股票、债券、管理员设备、可信合同奖励或 `set_nbt` 权威字段。无绑定凭证只是普通收集品，不能兑换奖励。

## 旧世界、性能与回退

- 旧世界无需重生成区块；制作调查板和贸易站即可体验完整 MVP。
- 关闭探索后拒绝新任务，但已有任务和托管仍会加载并可由到期流程退款。
- 每次定位只遍历有界的已登记聚落和仓库；没有逐 Tick 搜索、结构定位 API 或区块加载。
- 若探索存档与 escrow 不一致，只暂停 `EXPLORATION` 模块并保留资金，其他合同和市场继续运行。
- 回退时可禁用 `gameplay.exploration.enabled`；不要删除仍有活动 escrow 的存档节点。

## 仍需人工验收

正式启用随机遗迹前，仍需制作并目视检查 NBT 结构模板，在至少五个 seed 做频率抽样和截图，并测试新旧区块边界、关闭配置、服务端视距及两名玩家完整运输链。这些结果不能由蓝图解析测试或 GameTest 冒充。
