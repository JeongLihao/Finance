# Finance — Minecraft 服务器金融系统模组

Finance 为 Minecraft Forge 服务器加入一套虚拟经济、商品交易、公司经营、股票市场和中央银行调控系统。

- 版本：v0.4.1
- 平台：Minecraft 1.20.1 / Forge 47.4.16
- 作者：H-Jeong
- 更新日志：[CHANGELOG.md](CHANGELOG.md)

> README 只保留模组介绍、安装方式和游戏内操作说明；版本变化和修复记录请查看更新日志。

## 功能概览

### 账户系统

每个玩家都有独立银行账户，支持余额查询、转账、交易扣款、订单资金冻结和取消返还。新玩家首次加入会自动获得初始资金。

### 商品系统

模组默认注册三种基础商品：

| 商品 | 对应物品 | 分类 |
| --- | --- | --- |
| 铁锭 | `minecraft:iron_ingot` | 原材料 |
| 小麦 | `minecraft:wheat` | 食物 |
| 石头 | `minecraft:stone` | 建筑方块 |

管理员可以在 GUI 中添加更多 Minecraft 物品作为可交易商品。玩家拥有独立的虚拟商品库存，可以把背包物品存入商品库存，也可以从商品库存取回背包。

### 商品市场

Finance 包含两套商品市场：

- P2P 市场：玩家之间挂限价买单/卖单，价格匹配时自动撮合，支持部分成交和取消订单。
- 国际市场：系统做市商提供即时买卖报价，市场库存、成交动量、供需趋势和噪声共同影响价格。

市场失控时，中央银行会作为最大的 NPC 调控市场端货币和战略商品储备；普通波动先由国际市场自行消化，只有库存或现金进入危机区间时才触发央行介入。

### 公司系统

玩家可以创建公司，公司每天自动生产商品，并把一部分产出出售给国际市场换取现金。公司拥有现金、库存、经营策略、生产线等级、仓储等级和管理等级。

玩家公司支持：

- 调整经营策略
- 调整自动出售比例
- 升级生产线、仓储、管理
- 注资和提款
- IPO 上市融资

未上市公司不会向普通玩家公开真实估值；玩家公司栏只展示玩家自己的公司。

### 股票系统

系统初始公司默认上市，并自动生成股票。玩家公司可以通过 IPO 上市。股票系统支持：

- 股票持仓
- 限价订单
- 订单簿撮合
- 做市商兜底流动性
- 成交记录
- 公司盈利统计
- 周期性分红

股票价格由公司基本面、行业景气、交易动量和市场噪声共同决定。商品价格持续下跌时，会通过库存折价、利润恶化和行业风险折扣影响股票基本面，避免商品市场与股市走势脱钩。

### 事件系统

市场事件会随机触发，对商品行情产生临时影响：

| 等级 | 影响幅度 | 持续时间 |
| --- | --- | --- |
| 小事件 | 约 ±5%~10% | 0.5~1 MC 天 |
| 重大事件 | 约 ±15%~25% | 1~3 MC 天 |
| 黑天鹅 | 约 ±40%~60% | 2~5 MC 天 |

## GUI 操作

可以通过以下方式打开金融中心 GUI：

- `/market gui`
- `/finance gui`
- 默认快捷键 `F`

普通玩家可见 6 个标签页，管理员可见额外的管理标签页。

| 标签页 | 功能 |
| --- | --- |
| 行情 | 查看国际市场行情，选择商品并进行国际市场买卖 |
| 交易 | 创建 P2P 商品买单/卖单 |
| 订单 | 查看、吃单或取消商品市场挂单 |
| 库存 | 查看余额、虚拟商品库存和背包数量，进行存入/取出 |
| 公司 | 创建公司、管理自己的公司、发起 IPO |
| 股票 | 查看上市股票、下单交易、查看持仓 |
| 管理 | 管理员添加/删除商品 |

管理员商品管理页支持：

- 从手中添加：识别手持物品并添加为商品。
- 常用物品：按分类快速添加常见 Minecraft 物品。
- 已注册商品：查看和删除已注册商品。

## 命令

### 所有玩家可用

| 命令 | 说明 |
| --- | --- |
| `/balance` | 查询余额 |
| `/pay <玩家> <金额>` | 给其他玩家转账 |
| `/inventory` | 查看自己的商品库存 |
| `/market gui` | 打开市场 GUI |
| `/finance gui` | 打开金融中心 GUI |
| `/market orders` | 查看所有未成交商品订单 |
| `/market cancel <编号>` | 取消自己的商品订单 |
| `/market history` | 查看最近成交记录 |
| `/market history <商品>` | 查看指定商品成交历史 |
| `/market price` | 查看所有商品行情 |
| `/market price <商品>` | 查看单个商品行情 |
| `/market top` | 查看涨幅排行 Top 5 |
| `/market losers` | 查看跌幅排行 Top 5 |
| `/market overview` | 查看市场概览 |
| `/market international prices` | 查看国际市场报价 |
| `/companies` | 列出公开公司 |
| `/company mine` | 查看自己的公司 |
| `/company info <名称>` | 查看指定公开公司详情 |

### 管理员可用

管理员命令通常需要 OP 2 权限。

| 命令 | 说明 |
| --- | --- |
| `/market buy <商品> <价格> <数量>` | 挂商品买单 |
| `/market sell <商品> <价格> <数量>` | 挂商品卖单 |
| `/market international buy <商品> <数量>` | 从国际市场买入商品 |
| `/market international sell <商品> <数量>` | 卖商品给国际市场 |
| `/company create <类型> <名称>` | 创建公司 |
| `/finance give <玩家> <金额>` | 给玩家发放资金 |
| `/commodity give <玩家> <商品> <数量>` | 给玩家发放商品 |
| `/market debug nextday` | 手动推进一个 MC 天 |
| `/market debug pressure` | 查看事件计时器状态 |
| `/market debug fire <等级>` | 手动触发事件，等级为 `minor`、`major` 或 `blackswan` |

## 游戏内循环

| 间隔 | 内容 |
| --- | --- |
| 每个 MC 天，24000 tick | 重置日内统计、触发事件、公司生产和交易、国际市场补货/消耗、央行检查、股票基本面更新、公司利润结算和分红检查 |
| 每 3 分钟，3600 tick | 商品和股票刷新噪声、衰减动量、重算价格 |
| 每 1 分钟，1200 tick | 商品和股票衰减动量、重算价格 |

## 数据存储

数据保存在世界存档 NBT 中，服务器重启后会恢复。

| 数据名 | 内容 |
| --- | --- |
| `finance_data` | 账户、交易记录、订单、行情、事件、公司、股票、股票订单、成交历史、持仓、商品定义 |
| `finance_inventory` | 玩家和系统账户的虚拟商品库存 |

加载世界数据时，模组会先清空内存中的静态经济状态，再从当前世界存档恢复，避免连续切换世界时出现跨世界数据残留。

## 安装

1. 安装 Minecraft Forge 1.20.1，推荐 Forge 47.4.16。
2. 将 Finance 模组 JAR 放入服务器或客户端的 `mods` 文件夹。
3. 启动游戏或服务器。
