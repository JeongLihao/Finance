# Finance — Minecraft 服务器金融系统模组

给服务器加了一套虚拟经济系统

**版本：** 0.1.0  测试版
**平台：** Minecraft 1.20.1 / Forge 47.4.16  
**作者：** H-Jeong

---

## 都有什么功能

### 账户系统

每个玩家自带一个银行账户，存取转账都有。挂买单的时候钱会自动冻结，成交了扣掉，取消了退回来，不会出现超支的情况。

### 商品系统

目前有 4 种商品：铁矿、小麦、煤炭、钢材。每个玩家有自己独立的商品库存，跟 Minecraft 物品栏是分开的。

### 市场交易

**P2P（玩家对玩家）**

跟现实股票一样，挂限价单，想买就挂买单想卖就挂卖单。买方出价够高就自动撮合成交，支持部分成交。成交价按卖方的来，买方多付的差额自动退回去。

**国际市场**

不想等撮合的话可以直接跟国际市场交易，随时买随时卖。国际市场的买入价和卖出价有 5% 的价差，库存变化会影响价格，每天还会自动补货和消耗。

### 定价引擎

价格不是随机的，有三部分在起作用：

```
最终价格 = 基本面价格 × (1 + 交易动量) + 噪音偏移
```

| 因子 | 占比 | 说明 |
|------|------|------|
| 基本面 | ~70% | 国际市场库存偏离参考值 1% → 价格变动 5% |
| 交易动量 | ~20% | 每笔交易产生短期冲击，每分钟衰减 50% |
| 市场噪音 | ~10% | 随机游走，模拟运输成本和信息误差 |

价格最低能跌到基准价的 10%，最高能涨到 1000%。

### 公司系统

花 10,000 就能开公司，目前有 6 个行业可以选：矿业、农业、能源、制造业、物流、银行。每 MC 天公司会自动生产商品，原料不够时会尝试从国际市场购买；如果仍然凑不齐原料，当天不会凭空生产。可出售产出的一半会自动卖给国际市场变现，公司作为供应端卖货时只检查国际市场余额，不会错误要求国际市场先有库存。公司估值 = 现金 + 库存市值。

创建公司可以通过 GUI 完成；命令创建也支持中英文行业名，比如 `/company create 矿业 我的公司` 或者 `/company create MINING 我的公司`。GUI 和命令共用同一套创建逻辑，会统一校验、扣款、发放初始库存并注册公司。

服务器自带 4 个系统公司：铁矿集团、煤矿能源、麦田农业、钢铁制造。

**各行业的生产情况：**

| 行业 | 每日产出 | 每日消耗 |
|------|----------|----------|
| 矿业 | 铁×100、煤×50 | — |
| 农业 | 小麦×80 | — |
| 能源 | 煤×120 | — |
| 制造业 | 钢材×40 | 铁×80 |
| 物流 | 暂未开放生产 | — |
| 银行 | 暂未开放生产 | — |

### 事件系统

会随机触发一些事件影响价格，分三个等级：

| 等级 | 影响幅度 | 持续时间 | 触发间隔 |
|------|----------|----------|----------|
| 小事件 | ±5%~10% | 0.5~1 MC天 | ~3 小时 |
| 重大事件 | ±15%~25% | 1~3 MC天 | ~15 小时 |
| 黑天鹅 | ±40%~60% | 2~5 MC天 | ~75 小时 |

事件类型挺多的：运输延误、天气异常、矿工罢工、丰收消息、发现大型矿脉、粮食歉收、能源短缺、贸易禁运、战争爆发、金融危机什么的。

### GUI 界面

做了个金融中心 GUI，用 `/market gui`、`/finance gui` 或默认快捷键 `F` 打开。6 个标签页：

- **行情**：看国际市场行情，直接在这个页面就能买入卖出
- **交易**：P2P 挂单，自己定价格和数量
- **订单**：查看和取消自己的挂单
- **库存**：看余额和商品库存
- **公司**：查看或创建公司
- **股票**：查看系统公司股票、买卖股票、查看自己的持仓

GUI 已做过性能和布局修复：面板更宽、表格列距更稳、顶部标题和标签分开显示，按钮和长数字会截断显示；交易、取消订单、创建公司、股票买卖成功后会自动刷新界面数据。当前界面使用更接近 Minecraft 原生的浅色面板风格，减少深色块遮字和高对比装饰。公司页会显示系统公司和玩家公司列表，自绘按钮命中后会立即消费点击，避免按钮看起来卡住或没有反应。

### 股票系统

股票系统目前是 MVP 版本：服务器启动后会为系统公司自动生成股票，玩家可以在 GUI 的“股票”页按当前价直接买入/卖出。系统会保存股票列表、流通股、成交量和玩家持仓。股票页使用中文显示系统企业名称和股票代码，并兼容旧存档里已经生成的英文股票代码。

第一版暂不包含限价订单簿、K 线、分红、IPO 和玩家公司上市，这些会在股票系统稳定后再扩展。

## 命令

大部分查看类命令所有玩家都能用。玩家交易和创建公司主要通过 GUI 进行；部分命令行交易和调试命令保留给管理员使用。

### 所有玩家可用

| 命令 | 说明 |
|------|------|
| `/balance` | 查余额 |
| `/pay <玩家> <金额>` | 转账 |
| `/inventory` | 看商品库存 |
| `/market gui` | 打开 GUI |
| `/finance gui` | 打开金融中心 GUI |
| `/market orders` | 看所有未成交订单 |
| `/market cancel <编号>` | 取消自己的订单 |
| `/market history` | 最近成交记录 |
| `/market history <商品>` | 某个商品的价格历史 |
| `/market price` | 所有商品行情 |
| `/market price <商品>` | 单个商品详情 |
| `/market top` | 涨幅排行 Top 5 |
| `/market losers` | 跌幅排行 Top 5 |
| `/market international prices` | 看国际市场报价 |
| `/companies` | 列出所有公司 |
| `/company mine` | 看自己的公司 |
| `/company info <名称>` | 看指定公司详情 |

### 仅管理员（OP 2）

| 命令 | 说明 |
|------|------|
| `/market buy <商品> <价格> <数量>` | 挂买单 |
| `/market sell <商品> <价格> <数量>` | 挂卖单 |
| `/market international buy <商品> <数量>` | 从国际市场买入 |
| `/market international sell <商品> <数量>` | 卖给国际市场 |
| `/company create <类型> <名称>` | 创建公司（花 10,000） |
| `/finance give <玩家> <金额>` | 给玩家发钱 |
| `/commodity give <玩家> <商品> <数量>` | 给玩家发商品 |
| `/market debug nextday` | 手动推进一个 MC 天 |
| `/market debug pressure` | 看事件计时器状态 |
| `/market debug fire <等级>` | 手动触发事件（minor/major/blackswan） |

## 游戏内的循环

| 间隔 | 发生什么 |
|------|----------|
| 每 MC 天（24000 tick） | 触发事件 → 公司生产+交易 → 国际市场补货/消耗 |
| 每 3 分钟（3600 tick） | 市场噪音刷新 |
| 每 1 分钟（1200 tick） | 交易动量衰减 |

---

## 数据存储

所有数据都存在世界存档里，用的 Minecraft 的 NBT 系统。服务器重启数据不会丢。

- `finance_data`：账户、交易记录、订单、行情、事件、公司、股票、玩家股票持仓
- `finance_inventory`：玩家商品库存
