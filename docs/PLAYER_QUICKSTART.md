# 玩家快速上手

## 游戏内教程

- 登录后右上角会显示主线当前目标；它只认可服务端实际完成的背包、仓储、交易、合同与公司里程碑。
- 按 `J` 随时打开 13 页金融操作指南；按 `U` 隐藏或重新显示目标卡。
- 可选安装 Ponder 1.0.92+ 后，对主要金融物品按住 Ponder 的观察键，可观看九组不会改动真实资产的动画场景。
- 没有 Ponder 时，目标卡、手册、进度与配方奖励仍然完整，服务端不需要安装 Ponder。

你不需要使用全部系统，可以选择其中一条路线：

1. 生存交易：采集真实物品 → 制作仓库 → 存入 → 市场出售或完成合同 → 用收益建造升级。
2. 物流合作：在源仓库装入密封货箱 → 用背包或原版载具运输 → 在公司仓库或聚落交付 → 获得原合同/需求奖励。
3. 公司经营：创建公司 → 邀请成员并分配角色 → 绑定仓库和工厂 → 准备原料 → 每日生产 → 销售与扩建。
4. 高级金融：完成基础路线后制作证券终端 → 自愿使用股票、债券、基金、期货和保险；它们不是生存闭环的前置条件。

- 金融账本只显示本人轻量数据；高级股票、债券、基金、期货和保险在证券终端。
- 仓库操作必须站在控制器附近。特殊 NBT、命名、附魔或耐久物品不会被当成普通商品吞入。
- 合同奖励发布时已经进入 escrow；过期未完成会退还发行方，重复提交不会重复奖励。
- 公司设施每天最多生产一次。缺料、满仓、破产风险和模块暂停都会显示不同状态。
- 中央银行控制台只供管理员使用；普通玩家不能通过自定义客户端绕过权限。
- 调查板只会指向同维度一定范围内已经登记的聚落或仓库，不会显示矿物或全服建筑。完成调查必须在目标设施实际交互。
