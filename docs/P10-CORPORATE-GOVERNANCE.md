# Phase 10：公司治理、资本运作与重组

本阶段让上市公司的股票成为可核验的所有权记录。股东名册从股票持仓、卖单冻结和公司行动冻结记录派生；系统流动性作为单独的非投票口径显示，不会被伪装成玩家股东。

## 玩家操作

- 在“公司”页点击“治理”，可查看总股本、表决股、库存股、市值、企业价值、债务结构、主要股东、控制者以及进行中的回购和收购要约；页面底部可创建回购/注销提案、接受开放行动、执行已通过重组或刷新数据。
- 股东提案创建时锁定登记日投票权。之后买入的股票不能参与旧提案，卖出股票也不会抹掉已经登记的票权。
- 公司可在治理批准后发起固定价格回购。服务端会核对提案类型、公司、价格、数量与期限，授权只能消费一次。股东接受后股份被锁定，到期统一结算；回购股进入库存股，不参与投票和分红。
- 收购方发起公开要约时必须先托管最大收购金额。接受量超额时采用稳定的最大余数分配；不足最低数量则全部退款并释放股份。
- 经营者可取消尚未结算的回购，收购方可取消自己的要约。取消会先检查全部退款和股份返还容量，避免半结算。
- 库存股注销必须经过独立提案授权，执行时会同时减少库存股和总股本。

## 服务端规则

- 控制阈值为超过 50% 的表决权股份。控制权只授予治理权限，不会把公司现金、贷款、债券、保单或合同转给个人。
- 紧急再融资只在破产风险窗口内接受真实投资人资金；金额取自已通过提案的不可变快照，每个风险事件最多执行一次，不会清除逾期和信用历史。
- 重大库存资产交易由买方已通过提案确定卖方、商品、数量和价格，执行时仍要求卖方经营者确认，并同时检查买方现金、卖方库存及双方容量。
- 所有资本行动使用唯一业务键、结构化公告和交易流水。开放公司行动达到 1024 条时拒绝新增；已结束历史会在需要容量时清理，存档加载不会截断仍有关联资产的行动。存档版本为 26；旧存档缺少治理区段时按空行动加载，不生成资金或股份。

## 当前取舍

本阶段实现固定价格回购与简单公开要约，没有实现竞价收购、杠杆收购、母子公司、复杂合并报表、优先股或可转债。资产重组仅支持明确库存资产包，不自动承接目标公司的债务和保险责任。财务报告继续沿用现有有界历史结构，估值仅作信息参考，不作为系统强制成交价。

## 验证

自动化测试覆盖登记日交易隔离、重复投票、回购资金与库存股、超额要约守恒、失败/取消退款、库存股注销、存档恢复、历史版本迁移和网络行数/字段边界。游戏内仍建议人工检查 400×250 界面在不同 GUI 缩放比例下的文字裁剪和按钮命中区域。

全面核验还覆盖冻结资金回滚守恒、冻结股份成本恢复、破产期间开放公司行动释放、损坏治理记录隔离及托管资产返还。严重股本或托管差额会暂停股票与治理写入，但仍允许查看诊断数据。
