# 公司机器

玩家公司的产量全部来自世界里的实物：机器真的去收庄稼、砍树、挖矿、剪羊毛、加工原料，产出存进公司仓库，再按自动卖出比例每天卖掉。没有按天凭空生成的“抽象产量”。

NPC 公司和系统公司在世界里没有机器，仍按行业每天抽象生产再自动交易（`CompanyManager.tickAll`）。

## 机器一览

| 机器 | 方块 ID | 干什么 | 燃料 |
| --- | --- | --- | --- |
| 加工机 | `factory` | 两个原料槽 + 燃料槽 + 成品槽，像熔炉一样持续加工 | 冶炼类配方要烧 |
| 农场机 | `farm_machine` | 收割周围 9×9 成熟作物并补种；甘蔗收上半截，南瓜西瓜整块收 | 不用 |
| 伐木机 | `lumber_machine` | 只砍带天然树叶的树（不拆原木房子），捡树苗苹果并在树根补种 | 不用 |
| 采矿机 | `mining_machine` | 在正下方挖 5×5 竖井，一层层到基岩；铁镐挖不出东西的、带方块实体的跳过 | 每块烧燃料，一块煤 16 块 |
| 剪毛机 | `shearing_machine` | 给周围的羊剪毛；仓里没有空格就不剪 | 不用 |
| 公司收货箱 | `company_intake` | 放进来（或漏斗送进来）的商品每秒存进公司库存 | — |

加工机配方（`FactoryRecipe.ALL`）：小麦×3 → 面包，粗铁/粗铜/粗金 → 锭，圆石 → 石头，沙子 → 玻璃，线×4 → 羊毛，甘蔗×3 → 纸×3，纸×3 + 皮革 → 书。冶炼类（锭、石头、玻璃）要烧燃料。

漏斗：加工机只能往原料槽、燃料槽送，只能从成品槽取（燃料槽里烧剩的空桶也能取走）；采集机能从收获仓取、往燃料槽送。

采集机每次只干一件活，收获进 9 格仓；仓放不下就不动世界。改动方块前替放置者发一次 `BlockEvent.BreakEvent`，领地模组取消就跳过那一块。玩家扔下的、死亡掉落的物品不捡。

## 归属与公司仓库

- 放下机器时，放置者有某家公司的“管理生产”权限，机器就归这家公司，并登记一条机器记录（`CompanyFacilityRecord`）；否则是个人机器。拆掉时注销记录。每家公司最多 64 台机器（`CompanyFacilityManager.MAX_PER_COMPANY`）。
- 公司机器 16 格内有这家公司的仓库控制器时算“连着仓库”：每秒把能卖的产出存进公司库存，加工机按界面上选的配方从库存补原料和煤，采矿机补煤。没连仓库时产出留在机器里。
- 只有公司成员能打开公司机器；个人机器谁都能开。
- 存进公司库存的货按公司的自动卖出比例每天卖给市场，算公司营收。

## 档次、雇工和速度

- 档次 1～3，就是机器记录的等级。个人机器算 1 档。
- 每台机器每档 3 个岗位（`MacroLaborService.JOBS_PER_TIER`），从同维度最近的聚落按工资高低招工，规则见 [宏观经济](MACRO_ECONOMY.md#雇工)。
- 速度 = 档次倍率 ×（50% + 50% × 在岗比例），10000 = 1 档满员每 tick 推进一步。档次倍率是配置 `gameplay.facilityTiers.factoryTier{1,2,3}Throughput`，默认 1 / 2 / 4。附近没有聚落算满员；工资低于保留工资招不到人时只剩半速。
- 加工机每件的耗时、采集机干活的间隔另按 `factory.speedPercent` 缩放。

### 升档

在机器自己的界面里点“升档”（悬停能看到下一档要什么）。服务端走 `CompanyUpgradeService.upgrade`：要有管理生产权限、公司没有破产风险，从玩家背包扣材料、从公司账上扣钱。

| 升到 | 材料 | 公司付 |
| --- | --- | --- |
| 2 档 | 12 铁锭、8 铜锭、8 红石 | £20.00 |
| 3 档 | 8 黑曜石、12 石英、16 红石 | £80.00 |

档次记在机器记录上，机器拆掉后记录注销，重新放下是一台新的 1 档机器。

## 状态

机器每秒把状态写进记录，公司办公桌的机器清单、雇工、停业险都读这里：

| 状态 | 什么时候 |
| --- | --- |
| `ACTIVE` | 在干活；采集机周围暂时没活干也算正常 |
| `MISSING_INPUT` | 加工机缺原料或缺燃料 |
| `OUTPUT_FULL` | 成品槽 / 收获仓满了 |
| `DISABLED` | 停了，比如采矿机挖到底 |
| `BANKRUPTCY_HOLD` / `ORPHANED` | 公司破产冻结 / 公司已不存在 |

停业险只赔“非正常停工”：`MISSING_INPUT`、`OUTPUT_FULL` 这类持续两天以上、公司又有盈利历史的情况；`DISABLED`（挖到底这类正常停机）不赔。

## 进度

机器第一次把产品存进公司仓库时，给放置者和公司老板（在线的话）触发“生产启动”（`company_production`）；玩家登录时如果公司有 `ACTIVE` 的机器也会补发。

成就“工业革命”要有机器升到 3 档；“手艺人”要三台以上机器都还是 1 档且公司盈利。
