# 可访问性与本地化 RC 清单

自动化已验证：中英文键集合完全一致且无空值；主要入口窗口适配最小 GUI 区域；模型和贴图引用完整；状态方块同时有文字状态，不把颜色作为唯一业务信号。

真人目视需要在 GUI Scale 2、3、4 分别检查：

- Tab 顺序、Enter/Space 激活、Esc 返回和滚动区域不会困住焦点。
- 960×540、1280×720、1920×1080 下按钮可达，tooltip 不越过屏幕边缘。
- 正常/警告/受限/风险除绿黄红外还有文字、图标或状态名称。
- 关闭粒子后仍能通过方块状态和 actionbar 理解结果；音效受原版 `PLAYERS` 等音量类别控制。
- 负数、百分比、基点和长金额没有截断或难以区分的负号。
- 错误提示给出恢复动作，例如靠近设施、补足物品、整理账户或联系管理员。

这些项目尚未全部重新目视，因此 RC 报告必须保持“未达到发布标准”。
