# 玩家快速上手

## 游戏内教程

- 登录后右上角会显示主线当前目标；它只认可服务端实际完成的背包、仓储、交易、合同与公司里程碑。
- 按 `K`（或右键金融账本）打开金融中心，点标题栏“教程”进入教程中心：查看九阶段主线、阅读完整手册，也可以隐藏或重新显示目标卡。
- 主线之后，教程中心会继续记录实体物流、村庄援助、野外调查、高级金融、产业融资和风险管理六条可选路线；它们可以按任意顺序完成，点击未完成路线即可让 HUD 优先追踪它。
- 可选安装 Ponder 1.0.92+ 后，对主要金融物品按住 Ponder 的观察键，可观看十三组不会改动真实资产的动画场景。
- 没有 Ponder 时，目标卡、手册、进度与配方奖励仍然完整，服务端不需要安装 Ponder。

## 钱随时动，货在仓库进出

- **钱的事在哪都能办**：按 `K` 打开金融中心，存款、理财、股票、押注、开公司、上市认购、当老板，人在哪里都能操作。
- **货的事要回仓库**：放一个仓库控制器，站在它（或任意市场终端）旁，把背包里的货存进去。之后出门在外也能随时卖；买到的货也放进仓库，回到仓库或市场终端旁再取回背包。
- “马上买卖”、挂单、`/sell hand` 都只动仓库里的货，不碰背包。存入、取回（简单模式挂单页底部的两栏，或金融中心“库存”页）离开仓库和终端会被拒绝。
- 附魔过、改过名、有损耗、装着东西的物品不会被当成普通商品存进去或卖掉。

## 选一条路线

你不需要使用全部系统，可以选择其中一条路线：

1. **生存交易**：采集真实物品 → 制作仓库 → 存入 → 按 `K` 卖给市场或挂单，也可以完成合同 → 用收益建造升级。
2. **物流合作**：在源仓库装入密封货箱 → 用背包或原版载具运输 → 在公司仓库或聚落交付 → 获得原合同 / 需求奖励。
3. **公司经营**：创建公司 → 邀请成员并分配角色 → 放下公司机器（加工机、农场机、伐木机、采矿机、剪毛机、收货箱），16 格内放一个公司仓库 → 机器真的去收割、砍树、挖矿、加工，产出存进公司库存，每天按比例自动卖掉 → 机器升档、扩建。
4. **投资与金融**：金融中心“投资”页有股票、三档理财和押注，按进度解锁（存过理财解锁进取理财，买过股票解锁押注）。证券终端打开直接进投资页。
5. **上市**：公司估值够了，点“发起上市认购”：有 5 天认购期，NPC 投资者和其他玩家用真钱认购，认够发行量的一半才上市，钱进公司账上；不够就取消退款（上市费不退）。
6. **产业融资**：在公司绑定的仓库界面创建资本项目 → 完成必要治理 → 选择真实融资来源 → 资金到位后在仓库旁提交材料并施工 → 下一期查看财报和估值反馈。
7. **风险管理**：调查真实区域短缺 → 在银行柜台用公司真实库存申请质押贷款 → 在证券终端把采购 / 销售目标关联到真实个人期货仓位 → 购买有服务端证据的仓储或停产保险。

## 公司每天的开销

- 公司每天从现金里真付：工人工资、机器维护费（每台按档次 10 / 22 / 36）、库存利息（库存市值 × 央行利率 ÷ 365）和仓储费（库存市值的 0.2%）。
- 仓储升级让仓储费便宜，管理升级让维护费便宜、招工更快、招工半径更大。
- 现金不够时有多少付多少，没付上的记为欠付；上市公司有欠付或现金太低会进入破产风险。
- 央行加息时囤货更贵、村民也少花钱，物价会往下走；降息反过来。

## 其他提示

- 机器的状态（在干活、缺原料、仓满、停了）在公司办公桌的机器清单里能看到；缺料或仓满的机器会冒烟。
- 合同奖励发布时已经进入托管；过期未完成会退还发行方，重复提交不会重复奖励。
- 中央银行控制台只供管理员使用；普通玩家不能通过自定义客户端绕过权限。
- 调查板只会指向同维度一定范围内已经登记的聚落或仓库，不会显示矿物或全服建筑。完成调查必须在目标设施实际交互。
- 仓库中的“质押量”仍归公司所有，但不能提取、生产、出售或运输；还款会释放超额部分，清算失败时商品和债权都会保留。
- 经营对冲不会替你下期货单。首版只关联创建者自己的保证金账户，并明确不把个人期货盈亏写进公司财报。
