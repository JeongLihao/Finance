# Finance — Minecraft 服务器金融系统模组

Finance 给 Minecraft Forge 服务器加入一套虚拟经济、商品交易、公司经营和股票市场系统。

**版本：** 0.5.0-Beta  
**平台：** Minecraft 1.20.1 / Forge 47.4.16  
**作者：** H-Jeong

> 更新历史已完全移到 [CHANGELOG.md](CHANGELOG.md)。本 README 只保留模组介绍、安装方式和游戏内操作说明。

---

## 功能概览

### 账户系统

每个玩家都有独立银行账户，支持查询余额、转账、交易扣款、订单资产锁定和取消返还。

新玩家首次加入会自动获得 **1000 初始资金**。

### 商品系统

默认注册 3 种商品：

| 商品 | 对应物品 | 分类 |
|------|----------|------|
| 铁锭 | `minecraft:iron_ingot` | 原材料 |
| 小麦 | `minecraft:wheat` | 食物 |
| 石头 | `minecraft:stone` | 建筑方块 |

管理员可以通过 GUI 添加任意 Minecraft 物品作为可交易商品，支持原版物品和其他模组物品。

每个玩家都有独立的虚拟商品库存。商品库存和 Minecraft 物品栏分离，可通过存取功能在两者之间转移：

- **存入**：把物品栏里的物品存入虚拟商品库存，用于交易。
- **取出**：把虚拟商品库存里的商品取回物品栏，物品栏满时会掉落到地上。

### 商品市场

Finance 有两套商品交易市场：

- **P2P 市场**：玩家之间挂限价买单/卖单，价格匹配时自动撮合，支持部分成交。成交价按卖方定价，买方多冻结的差额会自动返还。
- **国际市场**：系统做市商提供即时买卖报价，买入价和卖出价有价差。国际市场库存会影响价格，并在每日发生补货和外部消耗。

只有进入行情表的商品才能与国际市场交易；其他已注册商品仍可通过 P2P 市场交易。

### 商品定价

商品价格由库存、交易动量和市场噪音共同决定：

```text
最终价格 = 基本面价格 × (1 + 交易动量) + 噪音偏移
```

| 因子 | 作用 |
|------|------|
| 基本面 | 国际市场库存偏离参考库存时，价格随供需变化 |
| 交易动量 | 近期交易会形成短期冲击，随后逐渐衰减 |
| 市场噪音 | 随机游走，模拟运输成本、信息误差和市场波动 |

### 公司系统

玩家可以花费 **10,000** 创建公司。公司每天自动生产商品，并把部分产出卖给国际市场换取现金。

| 行业 | 每日产出 |
|------|----------|
| 原材料 | 铁锭 ×100 |
| 建筑方块 | 石头 ×120 |
| 食物 | 小麦 ×80 |

公司估值由现金和库存市值组成：

```text
公司估值 = 公司现金 + 库存市值
```

服务器会初始化 3 个系统公司：

- 铁锭原料
- 石材工坊
- 麦田农庄

如果管理员删除某个商品，依赖该商品生产的公司会被强制退市。退市时会广播通知，关联股票会被移除，玩家持仓会按最后价格清算为金币。

### 股票系统

系统公司会自动生成股票；玩家公司也可以通过 IPO 上市。股票系统支持：

- 股票持仓
- 即时买卖
- 限价订单
- 订单簿撮合
- 做市商保底流动性
- 成交记录
- 公司盈利统计
- 周期性分红
- IPO 融资

股票价格由混合定价引擎驱动：

```text
股票价格 = fairValue 基本面锚 + 交易动量 + 市场噪音
```

股票交易会影响价格：买入会推高价格，卖出会压低价格。价格会逐渐向公司基本面估值回归，并被限制在合理区间内，避免无限暴涨暴跌。

### 事件系统

市场事件会随机触发，对商品行情产生临时影响。

| 等级 | 影响幅度 | 持续时间 | 触发间隔 |
|------|----------|----------|----------|
| 小事件 | ±5%~10% | 0.5~1 MC 天 | 约 3 小时 |
| 重大事件 | ±15%~25% | 1~3 MC 天 | 约 15 小时 |
| 黑天鹅 | ±40%~60% | 2~5 MC 天 | 约 75 小时 |

## GUI 操作

金融中心 GUI 可通过以下方式打开：

- `/market gui`
- `/finance gui`
- 默认快捷键 `F`

管理员可见 7 个标签页，普通玩家可见 6 个标签页。

| 标签页 | 功能 |
|--------|------|
| 行情 | 查看国际市场行情，选择商品并进行国际市场买卖 |
| 交易 | 创建 P2P 商品买单/卖单 |
| 订单 | 查看、吃单或取消商品市场挂单 |
| 库存 | 查看余额、虚拟商品库存和物品栏数量，进行存入/取出 |
| 公司 | 查看公司、创建公司 |
| 股票 | 查看股票、买卖股票、查看持仓 |
| 管理 | 管理员添加/删除商品 |

管理员商品管理页包含：

- **从手中添加**：识别手持物品并添加为商品。
- **常用物品**：按分类快速添加常见 Minecraft 物品。
- **已注册商品**：查看和删除已经注册的商品。

## 命令

### 所有玩家可用

| 命令 | 说明 |
|------|------|
| `/balance` | 查询余额 |
| `/pay <玩家> <金额>` | 给其他玩家转账 |
| `/inventory` | 查看自己的商品库存 |
| `/market gui` | 打开市场 GUI |
| `/finance gui` | 打开金融中心 GUI |
| `/market orders` | 查看所有未成交商品订单 |
| `/market cancel <编号>` | 取消自己的商品订单 |
| `/market history` | 查看最近成交记录 |
| `/market history <商品>` | 查看某个商品的成交历史 |
| `/market price` | 查看所有商品行情 |
| `/market price <商品>` | 查看单个商品行情 |
| `/market top` | 查看涨幅排行 Top 5 |
| `/market losers` | 查看跌幅排行 Top 5 |
| `/market overview` | 打开市场概览 |
| `/market international prices` | 查看国际市场报价 |
| `/companies` | 列出所有公司 |
| `/company mine` | 查看自己的公司 |
| `/company info <名称>` | 查看指定公司详情 |

### 管理员可用

管理员命令通常需要 OP 2 权限。

| 命令 | 说明 |
|------|------|
| `/market buy <商品> <价格> <数量>` | 挂商品买单 |
| `/market sell <商品> <价格> <数量>` | 挂商品卖单 |
| `/market international buy <商品> <数量>` | 从国际市场买入商品 |
| `/market international sell <商品> <数量>` | 卖商品给国际市场 |
| `/company create <类型> <名称>` | 创建公司，花费 10,000 |
| `/finance give <玩家> <金额>` | 给玩家发钱 |
| `/commodity give <玩家> <商品> <数量>` | 给玩家发商品 |
| `/market debug nextday` | 手动推进一个 MC 天 |
| `/market debug pressure` | 查看事件计时器状态 |
| `/market debug fire <等级>` | 手动触发事件，等级为 `minor`、`major` 或 `blackswan` |

## 游戏内循环

| 间隔 | 发生内容 |
|------|----------|
| 每 MC 天，24000 tick | 重置日内统计、触发事件、公司生产和交易、国际市场补货/消耗、股票基本面更新、公司利润结算和分红检查 |
| 每 3 分钟，3600 tick | 商品和股票刷新噪音、衰减动量、重算价格 |
| 每 1 分钟，1200 tick | 商品和股票衰减动量、重算价格 |

## 数据存储

所有数据都保存在世界存档 NBT 中，服务器重启后会恢复。

| 数据名 | 内容 |
|--------|------|
| `finance_data` | 账户、交易记录、订单、行情、事件、公司、股票、股票订单、成交历史、持仓、商品定义 |
| `finance_inventory` | 玩家和系统账户的虚拟商品库存 |

加载世界数据时，模组会先清空内存中的静态经济状态，再从当前世界存档恢复，避免集成服连续切换世界时出现跨世界数据残留。

## 安装

1. 安装 Minecraft Forge 1.20.1，推荐 Forge 47.4.16。
2. 将 Finance 模组 JAR 放入服务器或客户端的 `mods` 文件夹。
3. 启动游戏或服务器。
