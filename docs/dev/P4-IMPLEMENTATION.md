**CompanyIPOService.java**
- 检查流程：
  1. 验证公司存在且未上市
  2. 验证发行价 > 0 且发行数 > 0
  3. 冻结 5000 上市费用
  4. 计算总股本 = 发行数 / 40%
  5. 计算创始人持股 = 总股本 - 发行数
  6. 创建 Stock 对象
  7. 募集资金进公司现金
  8. 标记公司为已上市

## 🎮 P4 游戏体验

### IPO 流程

**玩家选择**
1. 在 GUI 公司页点击"上市"按钮
2. 弹出表单输入：发行价、发行数量
3. 确认后发送 `CompanyIPOPacket`

**服务端处理**
1. 冻结 5000 上市费用
2. 创建股票并注册到市场
3. 募集资金进公司现金
4. 返回成功消息和股票信息

**结果**
- 公司上市，股票可在市场交易
- 玩家创始人保留 60% 股份，不失控
- 募集资金用于扩大生产

### 股权结构

**发行配置**
- 发行占比：40% 流通
- 创始人保留：60%（≥51% 保证控制权）
- 总股本 = 发行数 / 0.4

**示例**
```
发行 4000 股 @ 100 元/股
→ 总股本 = 10000 股
→ 创始人持有 6000 股（60%）
→ 募集资金 = 40 万
→ 创始人拥有控制权 ✓
```

## ⚠️ 关键设计

- **上市费用 5000** —— 平衡进入门槛
- **创始人保留 60%** —— 保证公司创始人不失控（≥51%）
- **股票代码自动生成** —— 公司名前 4 字大写或补充字符
- **募集资金直接入账** —— 用于再投资，扩大生产能力
