# Minecraft-first 玩法设计

## 目标

Finance 保留完整金融内核，但玩家默认通过 Minecraft 的采集、运输、仓储、建造和协作进入经济系统。股票、债券、基金、期货、银行总账和监管工具属于高级层，不再是新玩家的默认入口。

核心循环是：发现需求 → 获取真实物品 → 运送并托管 → 交易或交付 → 获得资金与进度 → 建设更强的生产和贸易网络。

## 体验分层

- 随身账本：余额、锁定资金、近期记录和当前任务。
- 市场与仓库：真实物品托管、简单交易和本地合同。
- 公司经营：共享仓库、成员权限、材料交付、设施升级和简要财报。
- 高级金融：现有完整金融界面及其股票、固收、基金、期货和保险功能。
- 管理监管：央行政策、系统诊断和高风险管理操作。

## 不变量

- 隐藏入口不等于停止已有合同履约、订单取消、付息、分红或日结。
- 客户端只表达意图；资金、物品、权限、距离和结算均由服务端确认。
- 真实物品与托管商品之间必须原子转换，失败时不留下部分状态。
- 旧存档的账户、托管库存、持仓、冻结资产和合同不得因新玩法入口而丢失。
- 新功能优先通过 `finance.gameplay` 适配稳定金融管理器，不把世界逻辑塞入金融内核。

## 首轮边界

阶段 0 和阶段 1 只建立配置、入口枚举、界面模式和访问校验。轻量钱包、终端方块、仓库和合同将在后续阶段实现。当前旧完整界面被明确视为 `ADVANCED` 模式。
